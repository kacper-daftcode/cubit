# Test index

636 test files, 3220 `#[test]` functions (generated by `tools/gen_tests_index.py` from the `//!` doc comment of each file; `cargo test` runs them all, `tools/sync_table.py` runs them as the table-sync gate).

Conventions: a `bugNNN_*.rs` file is the executable specification of one numbered encoder/decoder finding (the number is the order the finding was made in, 2026-08..09 for most); the `//!` comment states the law it pins and the evidence. `sm120_*.rs` replay nvdisasm fixtures of measured forms (`tools/probes/`). `mk*`/`mercury*` pin the Mercury companion-section emitter. Fixtures live in `tests/fixtures/` (JSONL of words with NVIDIA's text; under 1 MB in total).
