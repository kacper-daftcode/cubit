# SM120 silicon errata — fix map (2026-08-18)

Canonical bug package: `results/cubit-bugs/` on the sm120 landing tree
(repro + silicon evidence). All fixes are at the source here; tests live in
`tests/bugs_errata_sm120.rs` (34 tests; the 249-word nvdisasm-12.8 census + 8 atoms pin decode+roundtrip byte-exact). Escape hatch: `CUBIT_DISABLE_ERRATA=1`
(table archeology only).
